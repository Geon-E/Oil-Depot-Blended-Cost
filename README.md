# Oil-Depot-Blended-Cost

KK 저장소 복합단가 업무용 웹 도구 모음입니다. 각 HTML 파일은 설치 없이 브라우저로 열어서 씁니다.

| 파일 | 내용 |
|---|---|
| `hub.html` | 두 도구를 왼쪽 세로 메뉴로 오가며 보는 화면 (사이트 첫 화면) |
| `ledger.html` | **복합단가 관리** — 사업장 원본 엑셀(단지·신도시·안동북부·침산)을 올리면 대시보드와 저장소별 일별 원장·입고 사입단가 입력·거래처별 출고를 만들고 엑셀로 내보냅니다. 인터넷 연결 없이도 동작합니다. |
| `index.html` | **경유 복합단가 사입 시뮬레이터 v2** (기존 앱, 변경 없음). 주소: `/index.html` |
| `vercel.json` | 사이트 첫 주소(`/`)를 `hub.html`로 연결 |

## 복합단가 관리 자료 올리는 법 (모든 PC 공통)
`data/` 폴더가 공유 자료입니다. 사이트를 열면 이 폴더를 자동으로 읽어서 어느 PC에서나 같은 화면을 보여줍니다.

1. **원본 엑셀**: 사업장에서 받은 원본(단지 상품수불장, 신도시·안동북부 출하장, 침산 .xls)을 `data/`에 올립니다. 같은 저장소 파일이 여러 개면 가장 최근 월·날짜 것을 씁니다. 지난 파일은 지워도 됩니다.
2. **설정(기초값·사입단가·증감)**: 앱에서 값을 입력한 뒤 `설정·마감 저장`으로 받은 JSON을 `data/`에 올립니다. 가장 최근에 저장된 JSON 하나가 적용됩니다.
3. 올린 뒤 1~2분 지나 사이트에서 `다시 불러오기`를 누르면 반영됩니다.

## 복합단가 관리 계산 규칙
기존 관리 엑셀과 같습니다. 그날 입고분을 먼저 가중평균으로 섞어 복합단가를 새로 내고, 출고는 그 단가로 차감하며, 증감(실재고 조정)은 수량에만 반영합니다.

## 데이터 보관 주의
- 이 저장소는 **공개**입니다. `data/`에 올린 원본(거래처·수량)과 설정(단가)은 누구나 볼 수 있습니다.
- 앱 화면에 직접 끌어다 놓은 원본과 입력값은 그 PC 브라우저에만 남습니다. 모두가 보게 하려면 `data/`에 올리세요.
